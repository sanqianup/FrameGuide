# 点选主体与本地构图引导

本轮为FrameGuide独立实现的增量，参考公开演示里“稳住、目标框、位置提示、滤镜建议、退出”的交互顺序。不复制DOKA代码、名称、图标、素材或后端。

参考由主线程实际观看的35秒公开视频：https://www.douyin.com/video/7654545937499290098 。约2秒显示分析稳住提示，8秒出现目标框，11秒倍率变化并有滤镜推荐，16秒有靠近与退出。录屏没有触点，不能证明变焦由AI自动触发，也不能推断模型、实时频率、深度或光学变焦实现。

## 使用流程

1. 相机就绪并稳定后，点“点选主体构图”，再轻点预览里的主体，同时对焦。黑边不接收选择。优先选取点内最小的人脸/人体检测框，没有命中时追踪点周围的纹理区域；不是身份识别。
2. 黄色实线显示当前追踪区域；青色虚线是规则生成、保持固定的二维目标框。屏幕提示主体在画面内应该向哪侧靠拢；不声称推算出相机应该前后/左右移动多少米。
3. 位置和大小接近目标且持续约0.65秒，框变绿色并给出一次到位触感；水平校正始终单独显示，不把“构图到位”当作水平校准成功。不会自动拍照。
4. 主体偏小且位置接近时，可由用户点按钮应用相对当前画幅的数字放大，单次最多1.8倍，设备倍率上限3倍（并遵守设备硬件范围）；不是焦距/距离估计或光学切换。放大后旧目标失效，需重新点选；可点“还原1×”。没有自动变焦循环。
5. 可随时“退出引导”，拍摄和原图保存仍独立可用。

## 性能与失效

- AVCapture预览保持独立；采样仍丢弃晚到帧。在同一utility分析队列上用VNTrackObjectRequest(.fast)+VNSequenceRequestHandler追踪点选区域，不为每帧重新做人脸/人体全图检测。首次点选时检测一次来选择种子。
- 正常状态追踪最多8Hz，构图/滤镜决策最多2.5Hz；fair状态5Hz/约1.54Hz；serious状态2Hz/约0.67Hz。低电量/内存压力沿用原策略降频，critical停止相机。本次没有真机性能数据，这些是调度上限，不是实测帧率。
- 规则目标不追着主体移动；位置判定有阈值、持续稳定时间和退出滞回。低频决策与追踪分开，避免每帧改变方向和推荐。
- 运动传感器判定不稳定、镜头/方向变化、会话重配/后台、追踪置信度不足或错误均使旧目标失效。保守策略要求明显移动后稳定并重新点选，不尝试跨大幅移动自动认回同一人。
- 主线程按帧采样时间检查1.2秒有效期；晚到、重排或停止更新的追踪不会续命。独立watchdog约0.3秒检查一次，清除过期显示。
- 选择/退出/失去主体、放大和原有场景变化都会作废旧云端票据。保留显式冻结预览确认、默认关闭上传和Keychain主机绑定；本轮未调用云端，不产生模型费用，不上传用户照片。

## 本地调色

自然、柔和人像、清透景物三个有限参数预设，复用现有Core Image渲染、原图对比与撤销。取景建议只根据本地选区是否来自人像检测及粗略亮度规则生成；不自动应用到预览或照片，没有学习审美、胶片仿真或生成式精修承诺。拍后用户手动选择，保存独立副本，原图不改写。
