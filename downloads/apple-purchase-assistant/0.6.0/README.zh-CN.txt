Apple 购买助手 0.6.0 · 简化候选实测版

先看这一句：界面与网页点选校准已整合；本方尚未实际安装扩展验收，Apple 完整下单流程也未验证。不是“保证抢购成功”的成品预设。

一、安装
1. 完整解压 ZIP。
2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 由你开启开发者模式，选择“加载已解压的扩展程序”。
4. 选择本包 extension 文件夹，该层直接包含 manifest.json。
5. 固定图标，点击“打开购买助手”。不用安装 Node、服务器或提供密码。
旧版文件未删除。为避免两个版本同时动作，安装测试新版前，请先停止旧版任务，并在浏览器停用旧版。不要并行启动两版。

二、日常最少操作
1. 选商品或粘贴 Apple 中国大陆商品链接，核对型号、颜色、容量和数量。
2. 选择网页已选收货地址，或载入/填写本次地址。
3. 填最高总价（必须包括税费和配送费）；开始时间为北京时间，留空立即。
4. 看“流程就绪”提示，确认本次授权，点击开始。停止按钮随时可用；已经发出的动作无法撤销。
已保存的完整校准计划可以直接使用，不需要再打开技术设置。保存计划不等于授权执行，每次开始仍须确认。商品预设仅预填已记录的商品资料，不代表后半段结账已适配。

三、首次遇到未知页面
没有完整流程时，开始会引导你标记页面，不会盲点商家按钮。
- 打开“标记网页步骤”，点击“查找 Apple 页面并授权”。权限只覆盖 www.apple.com.cn 和已经观察过的 secure6.www.apple.com.cn。
- 选择已打开的 Apple 页面，按向导一次标记一项。鼠标移到具体按钮、信息位置或地址输入栏，在扩展浮层确认。按 Esc 可取消。点选只记住定位信息，不替你按商家按钮、不读取输入值或地址摘要。
- 向导会让你标记动作、商品/金额证据以及完成后的独立状态。含税运费、不扣款、订单结果等文字必须来自网页公开提示，不得凭空填写。
- 需要进入下一页面时，先退出点选，再由你自行操作；之后重新选择页面标记。最终订单没有真实结果可核验时，保留未完成，不能为了校准而创建订单。
- 可保存未完成进度，下次同商品/同地址模式继续。只有完整计划通过检查，才能“保存可用流程”。无需写 selector 或 JSON。
- 点选采用唯一语义目标与稳定属性；动态 ID、个人信息、歧义目标或不支持的页面会拒绝。若网页过早注册的事件监听器先执行，扩展无法保证拦截所有页面代码；有疑问请按 Esc 取消。
技术映射、旧模式和测试入口都在高级设置内，保留但默认收起。

四、保留的购买执行能力及边界
同一个计划串联：规格 → 加购物袋 → 填写/确认地址 → 复核订单 → 仅创建明确不扣款的未付款订单 → 停在支付前。
每次动作前检查精确页面、唯一可见可用目标、商品规格、数量与预算；DOM 变化即唤醒，不等待 window.load，不反复网络刷新。点击后必须有独立状态确认。
地址支持标准 autocomplete、label/ARIA/name 语义及原生省市区级联，填写触发 input/change，重绘后重新定位并校验。非标准地区弹层、缺失选项、未知必填字段需要校准或手动处理。
不填密码、验证码、银行卡或身份验证字段。你在自己的浏览器自行登录 Apple。
“提交订单”四个字不证明不扣款。若没有独立无扣款声明，或涉及支付/授权扣款，停给你处理。未知提交不重试；最终真实提交锁不能通过停止、重启、换计划解除。先到官网核对订单。
维护、暂停、登录、排队和验证码页面停止，不绕过、不高频刷新。

五、地址资料
默认只在会话内使用，可清空。仅在你勾选本机保存并点击保存时，才写入当前浏览器独立地址预设；它未加密、不跨设备同步，不进入普通配置、诊断或安装包。可删除本机预设并停止相关任务。代码没有上传地址到模型或其他服务的接口；真实填充仅向你配置并授权的 Apple 页面输入。

六、先验收假商城
在高级设置打开“完整模拟商城”，使用虚构商品/地址/提交，检查正常、DOM 替换、延迟级联、停止、未知结果和延迟提交。页面记录你的实际浏览器耗时及提交次数；此包不预填虚假的浏览器性能结果。
开发端只完成 Node 模拟 DOM/API 回归和静态独立审计。云浏览器工具拒绝访问扩展安装内部页；不能绕过该限制。HTTP 演示跨环境连接也未成功，因此不能把本包说成已安装验收。

已观察 Duo 配置控件、18 Pro 加购/附件/购物袋、secure6 登录入口及部分送货地区选择。Duo 1TB 夜空色指定 SKU 仅部分公开文本核实，不能复制未验证的启用/选中状态。
完整地址、复核、付款顺序与最终提交 DOM 尚未实页验证。通用执行器可配置，但未知部分没有偷偷填入猜测的 Apple 预设。详见 OBSERVED-APPLE-FLOW.md。
