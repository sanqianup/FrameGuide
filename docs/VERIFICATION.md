## 真机验收流程（全部待执行）

| 场景 | 操作与通过条件 |
| --- | --- |
| 首次安装 | 相机允许/拒绝分别走通；拒绝后按钮不可拍，设置入口可用；不请求麦克风或读取既有相册 |
| 免费安装 | 用户自行使用 Personal Team；记录签名/安装成功，7 天重装与数据保留；不启用付费会员 |
| 镜头 | 依次切换所有实际镜头与前置；无可用镜头不显示；连续切换时不崩溃、不错误开快门；物理切换可短暂停顿 |
| 取景与拍摄 | 持续 10 分钟取景，同时移动/对焦/拍摄 30 张；预览无长期冻结，存储完成前禁止重复快门，原图顺序与方向正确 |
| 原图完整性 | 检查存储字节与记录 SHA-256；添加到 Photos 前后原图资源尺寸、方向、EXIF和文件内容核验；前置预览镜像与原图非镜像符合说明 |
| 调色和撤销 | 调色、撤销、恢复、原图比较；导出是独立文件，原图哈希不变；超过 20 步撤销边界和重进页面行为明确 |
| 水平与旋转 | 横竖屏分别核验正负方向、校准/复位；前后镜头框与实际主体重合；指向正上/下时提示不可用，无 90°/180°跳变错误 |
| 构图稳定 | 同一静物/人脸稳定取景不反复左右跳；突然移动、换主体、遮挡、多脸、丢失主体后旧建议清除；镜像横向提示与实际移动一致 |
| 生命周期 | 来电/控制中心/其他相机占用/锁屏/后台/恢复；快门状态正确，恢复可用，无后台相机常驻；媒体服务重置按路径降级 |
| 资源压力 | 低电量、系统热状态、内存警告下检查降频和缓存释放；critical 暂停并提示，降温恢复；磁盘不足显示未保存与可重试，不能报成功 |
| 云端默认状态 | 无密钥/禁用/上传关闭时明确不可用，无网络照片请求；任意连接测试需确认，不能报图片能力已验证 |
| 手动取景确认 | 稳定取景点“分析当前画面”，只取下一帧；未确认不发网；确认页实际主机/模型/缩略图一致。关闭确认、超过15秒、移动、旋转或切镜头后不改发新图 |
| 云端真实请求（另需授权） | 用户本人配置官方密钥，确认取景冻结帧或某张照片；只上传去 EXIF 的1024px预览；响应与帧/照片绑定；本地预览/快门不会等待云端 |
| 网络失败 | 受控测试 401/403/429/5xx、断网、超时、3xx重定向、超限、错字段/越界值；显示错误、本地功能继续、无自动重复请求 |
| 过时响应 | 慢响应时移动、切镜头、旋转、场景亮度变化、拍摄、取消、退出、后台或关闭上传；返回不得显示成新场景建议或覆盖照片；8秒限流不因取消/切镜头重置，采样后30秒过期，丢弃计数可观察 |
| 生成式编辑 | 另有明确兼容服务才能测；确认细节改变风险，输出独立副本，不把 MiMo 看图当图像生成 |
| iOS 27 | 使用对应 SDK 重新编译，再用对应系统设备验证上述场景；单独记录，不能继承18.5结论 |
