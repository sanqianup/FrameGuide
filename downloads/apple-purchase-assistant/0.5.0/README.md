# Apple 购买工作流 0.5.0 候选实测版

本目录仅存放浏览器扩展安装包和中文说明。

- [下载插件 ZIP](./apple-purchase-workflow-0.5.0-candidate.zip)
- [中文安装说明](./apple-purchase-0.5.0-install-guide.zh-CN.txt)

登录有权访问本私有仓库的 GitHub 账号，打开 ZIP 文件页面，点击 Download raw file（下载原始文件）。完整解压后，在 Chrome/Edge 的扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，选中直接含 manifest.json 的 extension 文件夹。

## 验证状态

候选版，不是已完成真实浏览器验收的成品。314 项 Node 回归测试通过不等于 Chrome/Edge 实际加载或端到端验证。真实扩展加载、Apple 完整结账和最终订单提交尚未验收；未知页面会停止，不能保证抢购成功。请先阅读安装说明并运行包内模拟商城。

包内仅有代码、说明与虚构测试资料；不包含用户地址、电话或登录凭据。
