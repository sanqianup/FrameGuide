# 执行架构与数据边界

## 调度

| 路径 | 执行位置 | 边界 |
| --- | --- | --- |
| 相机预览 | AVCaptureVideoPreviewLayer | 不等待 Vision、Core Image 或云端 |
| 会话、设备、拍摄状态 | camera.session 串行队列 | begin/commitConfiguration、start/stop、镜头、对焦、拍摄均在此执行 |
| Vision | camera.vision 串行 utility 队列 | alwaysDiscardsLateVideoFrames；同步完成一帧后再处理最新可交付帧；无自建视频帧数组或任务积压 |
| 姿态 | 独立 Core Motion OperationQueue | 15Hz 采样，仅标量状态送回主线程 |
| 文件保存/校验/相册导出 | PhotoStore actor | 不在主线程编码原图；保留捕获字节，原子写入与保护属性 |
| 本地渲染 | PhotoRenderer actor | 单次本地渲染，预览最长边 1600px，导出使用原始分辨率；CI 缓存可释放 |
| 云端 | RemoteClient actor + ephemeral URLSession | 全局一个请求，流式按字节限长读取，超时、取消、不重定向、不缓存、不自动重试 |
| UI 状态 | MainActor | 不调用阻塞式 startRunning、Vision、文件 I/O 或全尺寸渲染 |

分析默认每 0.4 秒最多一帧（2.5Hz），显著性仅每第三个已准入帧。低电量、内存警告、温热/较热时降低采样；critical 热状态暂停相机和分析，降温后重新启动。内存压力标记在本次 Engine 生命周期内保持保守降级。正常拍摄期间暂停 Vision；完整的照片保存交由独立 actor 执行。

原生预览目标是稳定 30fps；这是配置偏好，不能当作实测结果。视频 delegate 队列被 Vision 占用会丢掉分析帧，预览不依赖这条队列。`deliversPreviewSizedOutputBuffers` 降低分析输入尺寸，但设备协商效果必须在真机检查。

## 正确性

- 拍摄按钮在会话未就绪、拍摄/保存中或存在未保存原图时禁用。Engine 再次检查状态，防止 UI 状态延迟造成误操作。
- 全部可用物理镜头来自设备发现，不伪造不可用倍率。切换失败尽量保留原输入，不宣称无缝切换。
- 预览显示整个传感器图像（可能留黑边），网格和主体框位于同一图像矩形；旋转同时更新预览与视频/照片连接。
- 视频帧由 AVFoundation 物理旋转后以 `.up` 输入 Vision；转为左上原点并按前置镜像修正。前置取景镜像，原始照片不镜像。
- 分析结果带 generation；停止、旋转、镜头切换、拍摄、策略变化时失效，主线程交付前再次核对。
- 稳定/不稳定转换由实际接入 FrameAnalyzer 的 AnalysisEpoch 推进代次。运动开始时主线程立即清空已显示建议与主体框；不稳定时不准入Vision，运动前在途结果在推理完成和主线程交付时均被拒绝，即使其间已重新稳定也不能复活旧提示。稳定转换还在串行分析队列重置构图平滑/限频状态。
- 本地构图使用 EWMA 平滑、0.45 秒防抖、对齐滞回、0.9 秒主体丢失过期。运动时清空旧目标；大幅主体跳变重选目标。多人的身份跟踪未实现，拥挤场景需验收并谨慎采纳建议。
- 拍后云端针对不可变 PhotoRecord，RequestGate 同时核对 request UUID 与 photo UUID；取景云端使用 LiveRequestGate 绑定采样 UUID、镜头、旋转角和场景 epoch，需显式冻结预览确认。移动、粗粒度画面变化、镜头/方向切换、拍摄、页面退出或后台会推进 epoch、取消网络并清除旧建议。
- LiveRequestGate 采样间隔至少 1.5 秒，请求至少间隔 8 秒且取消/场景切换不清零限流。取样最多等待约 2.8 秒，确认有效期 15 秒，结果/建议最长保留到采样后 30 秒。所有回调在显示前再次核对 ticket 与时效；没有自动拍摄或自动网络上传。
- 原图独立保存，SHA-256 导出校验，调色只产生副本。临时保存失败保留当前内存数据并显示重试；不宣称磁盘失败时原图已保存。

## 生命周期与资源

权限请求由系统处理；拒绝后提供 App 设置入口，App 不替用户修改系统权限。非活动状态停相机、停姿态、取消云端并清空构图显示；恢复前台重新核验相机权限。拍摄后本机保存申请有限后台任务，不能保证 iOS 在任意锁屏/强杀下完成保存。

会话中断禁用快门，结束后按用户期望恢复；媒体服务重置最多自动恢复两次，其他错误提示人工重试。critical 热状态不自动继续拍摄，只恢复预览可用状态。渲染缓存遇内存警告清空，图库不一次加载所有原图，照片页只解码有限尺寸预览，离开后释放图片与取消请求。

权限请求去重及前后台意图由纯 Swift CameraStartIntent 管理；权限回调晚到且用户已停机时不启动摄像头。重复点击当前镜头直接返回，不会先把就绪状态关掉。镜头切换失败后的 ready 事件重新绑定实际选中镜头，避免云端 scene 使用错误镜头标识。

实时缩略图只在用户点击后从下一张可交付视频帧编码，始终不持有历史 CVPixelBuffer 队列。编码走分析 utility 队列，不上主线程，也不占相机会话队列。8×8 亮度网格最多 5Hz 运行，仅用于保守失效，不是语义场景识别；姿态移动也是独立失效源。无主体、低对比度或亮度接近的场景切换仍有漏判可能，应采纳当前冻结帧范围内的建议。

## 数据

```
Application Support/FrameGuide/Photos/<UUID>/
  original.heic (或 original.jpg 等系统实际格式)
  record.json (创建时间、文件名、SHA-256)
```

目录使用文件保护。原始文件无 App 级自动清理策略；使用者应定期把需要的照片添加到系统相册。App 卸载会移除本机目录；免费签名续期应保留相同 Bundle ID 重装，先导出重要照片。元数据写入时进程突然被强杀可能留下未入列表的原图，当前尚无自动修复目录工具，这是验收和后续恢复功能的已知限制。

照片目录遵循 iOS 常规备份行为；“本机处理”表示本 App 不自行上传，并不承诺关闭系统 iCloud/设备备份。用户自行决定系统备份设置。

密钥按服务类型、HTTPS 主机及端口隔离在 ThisDeviceOnly Keychain，不写入 UserDefaults、源码、日志、导出包或 CI。用户更换主机后需要为新主机保存密钥。

## 可观测性

诊断页面记录本次进程的数值，不持久化请求内容、照片或密钥。Vision 耗时以 monotonic uptime 测量；引导间隔指分析采样间隔；视频回调 FPS 指 delegate 已交付帧的数量，不能代表真实显示 FPS。云端计时包括本地上传预览编码、网络和模型等待；真实预览、快门和存储延迟由 Instruments/真机验收表补齐。
