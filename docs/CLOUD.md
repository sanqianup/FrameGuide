# 自定义云端服务契约

当前没有真实模型请求；合成响应单元测试已包含在云端macOS通过的35项核心测试中，不等于真实端点/密钥/看图能力已测通。

## 小米官方默认模板

| 项 | 值 |
| --- | --- |
| 完整请求地址 | `https://api.xiaomimimo.com/v1/chat/completions` |
| 模型 | `mimo-v2.6-pro` |
| 鉴权 | `api-key` 头；用户安装后自行输入本机密钥 |
| 参数 | `thinking.type=disabled`，`response_format.type=json_object`，`stream=false`，`max_completion_tokens=600` |
| 启用状态 | 关闭；上传开关关闭；能力确认关闭；无密钥 |

依据 [官方首次调用](https://mimo.mi.com/docs/zh-CN/quick-start/summary/first-api-call)、[图片理解](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/multimodal-understanding/image-understanding)、[深度思考](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/text-generation/deep-thinking)、[结构化输出](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/text-generation/structured-output)，核查于 2026-10-15。JSON 模式只保证语法，不保证字段和范围；App 必须自行校验。关闭思考减少额外推理等待，不保证某个网络响应时间。

## 本机使用步骤

安装后，用户进入设置核对端点与模型，确认服务实际支持 `image_url` 图像输入，在 SecureField 输入密钥并明确点“保存”。密钥只进入此设备 Keychain，主机变化不会自动把旧密钥带到新主机。端点必须完整 HTTPS、无 URL 用户名/密码/query/fragment；不自动猜路径，不跟随重定向。

“连接测试”经确认后仅发送一条无照片文本请求；这也可能计费，只能证明文本端点响应。不会据此声称模型支持看图、修图或正确参数。没有免费通用的生成式编辑连通性测试，设置页只提供配置说明，真实编辑请求需用户单独确认。

取景页增加“分析当前画面”：仅在相机可用、稳定、已配置有效服务及密钥、上传开关开启时可操作。先在本机取下一帧并展示冻结缩略图、实际接收主机、模型与费用提示，再由用户明确点“确认上传这一帧”。没有确认就没有网络照片请求；不以确认旧图的权限改发新图。采样超时、移动、镜头/方向切换、粗粒度画面变化、拍摄、后台或退出会取消并失效。确认窗口最长 15 秒，响应及建议有效到采样后 30 秒；至少间隔 8 秒请求，不能靠切镜头或取消绕过。另有独立“停止”按钮。

拍后照片也可从复查页手动触发；两条路径共享全局单请求。发送最长边 1024px 的 JPEG，使用 ImageIO 从像素创建，不带源 EXIF/GPS/IPTC。不是原始全尺寸文件，没有连续自动上传或后台上传。API 服务自行决定处理和保留行为，用户应核对其隐私政策和额度。

看图输出必须是 chat completions 的 `choices[0].message.content` JSON 字符串，内容严格符合：

```json
{
  "advice": "一句可实际执行的拍摄建议",
  "tone": {
    "exposureEV": 0.08,
    "saturation": 1.025,
    "warmth": 0.025,
    "contrast": 1.015
  }
}
```

必须包含且仅包含这些字段。`advice` 为非空字符串，最多 250 个 Swift 字符；所有数值必须有限且分别落在 `[-0.5,0.5]`、`[0.85,1.15]`、`[-0.15,0.15]`、`[0.9,1.1]`。拒绝 Markdown 围栏、散文、缺字段、多字段、工具调用、空响应或越界数据。响应主体上限 1MB，不按模型提供的 URL 再下载。校验通过才本地应用颜色参数；不执行模型任意命令。

## 生成式编辑

另有独立配置，不使用 MiMo 看图接口冒充图片生成。仅提供兼容 `multipart/form-data` 图像编辑适配器：`model`、`prompt`、`response_format=b64_json` 和 `image` 文件字段；返回 `data[0].b64_json`。某服务若使用不同协议，必须增加专门适配并测试，不能仅换地址就承诺可用。

响应上限 25MB，解码图像数据上限 18MB、24MP；不跟随图像 URL，不偷偷下载第三方位置。生成式结果只显示为独立候选，需用户明确保存，可能改变身份和细节。原图及本地调色路径始终独立。

## 失败和取消

全局单请求（包括连接测试）；页面退出、后台或用户取消后取消 URLSession 任务并失效 ticket。响应同时绑定请求和照片 UUID，旧完成事件不能释放新请求或覆盖当前照片。超时/断网/取消、HTTP 401/403/429/5xx、重定向、超限和错误格式均显示失败并保持本地能力；不自动重试，避免重复请求或不确定计费。网络取消不代表服务端一定停止计费。

取景路径额外绑定镜头、角度及场景代次，不把结果写入尚未拍摄的照片或自动应用颜色参数。本地 Vision 文案与“云端 · 模型名”结果分开显示；没有真实返回就不会出现云端建议成功状态。场景变化检测仅使用姿态和低分辨率亮度差异，不能保证所有内容变化都被识别。

真实端到端验收仍需用户安装、配置有效密钥，并明确同意测试 API 及上传某张照片。当前未提供、读取或使用任何用户 API 密钥；没有请求小米或其他服务，也未训练或下载模型。
